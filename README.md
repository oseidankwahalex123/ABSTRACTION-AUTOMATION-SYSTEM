# ABSTRACTION-AUTOMATION-SYSTEM
This project demonstrates the concept of abstraction object oriented programming using python.

FEATURES
* Abstract class: building system
* Abstract methods:
  .start()
  .stop()
  .status()
*Child classes:
 .AirConditioningSystem
  .LightningSystem
  .SecuritySystem
  .FireAlarmSystem
*Demonstrates polymorphism by storing objects in a list and processing them through one loop
*Shows extensibility by adding FireAlarmSystem without modifying the existing processing loop
